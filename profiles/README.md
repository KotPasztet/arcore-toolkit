# Profiles

Put the binary device profiles you extracted from **your own** ARCore
installation here (see `docs/02-profiles.md`).  Profile files are Google's
proprietary data and are intentionally not part of this repository.

Typical names match the globs in `profiles.json`:

```
profiles/example_pADuJF.pb
profiles/hwmar_nJH8dB.pb
```

`*.pb` and `*.zip` are ignored by git.
